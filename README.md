# Solicitudes de soporte tecnico

Programa en Python con Tkinter para registrar solicitudes de soporte tecnico del laboratorio de informatica

## Cómo ejecutar el programa

1.	Instalar Python en la computadora
2.	Guardar el archivo solicitudes.py en una carpeta
3.	Abrir el archivo con Python (En VS Code Ctrl + F5)
4.	Se abre la ventana. Ya puedes llenar el formulario
   
El archivo de datos solicitudes.csv se guarda en la misma carpeta donde está solicitudes.py


## Que hace

- Registra solicitudes y valida los datos antes de guardar
- Guarda todo en `solicitudes.csv` (en la misma carpeta del programa)
- Permite consultar las solicitudes guardadas
